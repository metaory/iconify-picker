Iconify Picker

A modern, zero-dependency icon picker built as a custom element. Drop in anywhere — no framework required.

⚡ Zero Dependencies
Built with vanilla JS, no frameworks required
🎨 Fully Themeable
Style with CSS custom properties
🧩 Framework Agnostic
Works with any framework or vanilla HTML
🎯 Multiple Modes
Inline, button, or manual control
Inline Mode
Always visible picker for forms and settings
Button Mode
Toggle picker with a button click
Manual Mode
Programmatic control for custom UIs
Install via CDN
<script type="module" src="https://unpkg.com/iconify-picker"></script>
Install via npm
npm install iconify-picker
