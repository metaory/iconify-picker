Inline Mode

Always visible picker for forms and settings.

Usage

<iconify-picker collection="mdi"></iconify-picker>

Attributes

  • collection - Icon collection name (required)
  • page-size - Number of icons per page (default: 48)
  • theme - Theme mode: "light", "dark", or "auto"
  • selected - Pre-selected icon name

Events

  • icon-selected - Fired when an icon is selected
  • change - Fired when the selected icon changes
