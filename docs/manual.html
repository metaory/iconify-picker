Manual Mode

Programmatic control for custom UIs.

Usage

<iconify-picker id="picker" mode="manual" hidden collection="mdi"></iconify-picker>

<script>
  const picker = document.getElementById('picker');
  picker.show(); // Open picker manually
</script>

Methods

  • show() - Show picker
  • hide() - Hide picker
  • toggle() - Toggle visibility
  • reset() - Clear filter/selection
  • focus() - Focus search input

Attributes

  • mode - Set to "manual" for manual mode
  • collection - Icon collection name (required)
  • page-size - Number of icons per page (default: 48)
  • theme - Theme mode: "light", "dark", or "auto"
  • selected - Pre-selected icon name

Events

  • icon-selected - Fired when an icon is selected
  • change - Fired when the selected icon changes
